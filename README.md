# Simply 📱

Un'app nativa iOS (SwiftUI) pensata per genitori: lista della spesa e promemoria/calendario sincronizzati in tempo reale.

## Stato Attuale (Test Build)
- Schermata di test completamente grigia (nessuna barra, nessun componente, verifica apertura pulita).
- Sviluppata in SwiftUI nativo.
- Compilazione automatica tramite GitHub Actions su macOS.
- Compatibile con sideloading tramite **SideStore**.

## Installazione via SideStore
1. Vai nella sezione **Releases** di questa repository.
2. Scarica il file `Simply.ipa`.
3. Apri **SideStore** sul tuo iPhone e premi `+` per installare l'IPA.
